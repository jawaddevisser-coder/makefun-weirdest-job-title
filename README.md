## The entry

> **Senior Vice President of Lost Remote Controls**

A real-sounding corporate title with one hilariously specific twist: the whole executive ladder, dedicated to the remote controls that vanish between the couch cushions.

## How it works

`main.ts` writes the title to `/output/entry.txt` (45 characters, UTF-8, non-blank) and enforces the 1–60 character gate itself before writing.

Run it with:

```sh
node main.ts
```
